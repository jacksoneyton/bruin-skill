## What
Build the local development foundation for Bruin pipelines. You will install the toolchain, create a first local pipeline, learn the core concepts, and then build a complete NYC Taxi pipeline.

## How
This course combines the standalone local pipeline guides into one learning path. Use it when you want the recommended order, then open each guide for the detailed steps.

## Before you start
Git installed
A terminal and a code editor such as VS Code or Cursor
